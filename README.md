# 🐧 Expedição FTTH 

## Um Jogo Educativo para o Ensino Prático da Topologia e Montagem de Redes FTTH (*Fiber to the Home*)

O **Expedição FTTH** é um jogo educativo desenvolvido como **Trabalho de Conclusão de Curso (TCC)** do curso de **Bacharelado em Ciência da Computação** da **Universidade Estadual do Piauí (UESPI)**.

O projeto tem como objetivo auxiliar no ensino da **topologia** e da **montagem de redes FTTH (*Fiber To The Home*)** por meio de uma experiência **interativa**, **educacional** e **gamificada**.

Mais do que um jogo, o **Expedição FTTH** busca transformar conceitos técnicos de elementos e infraestrutura de redes ópticas em uma ferramenta de aprendizagem **acessível**, **visual** e **intuitiva**.

---

# Sobre o Projeto

As redes **FTTH (*Fiber To The Home*)** utilizam cabos de fibra óptica para levar a internet diretamente até a residência do cliente final, proporcionando maior velocidade, estabilidade e qualidade de conexão.

O jogo foi desenvolvido para auxiliar estudantes e iniciantes na compreensão dos principais componentes de uma **rede FTTH**, permitindo a interação com elementos como:

- **CTO** (Caixa de Terminação Óptica);
- **CEO** (Caixa de Emenda Óptica);
- **Postes**;
- **Cabos Drop ou AS** (Autossustentável);
- **POP** (*Point of Presence* ou Ponto de Presença);
- **Iglus** (Representação das residências).

A proposta utiliza conceitos de **gamificação** para tornar o processo de aprendizagem mais **dinâmico**, **interativo** e **envolvente**.

---

# Objetivos

- Auxiliar no ensino de **redes FTTH**;
- Apresentar os principais componentes da **infraestrutura óptica**;
- Simular o planejamento de uma **topologia de rede**;
- Proporcionar uma experiência **educacional interativa**;
- Utilizar **gamificação** como ferramenta de apoio ao aprendizado;
- Facilitar a compreensão da montagem e organização de redes FTTH.

---

# Funcionalidades

- Inserção de **CTO** ou **CEO**;
- Inserção de **Postes**;
- Inserção de **Cabos Drop ou AS**;
- Inserção de **POP**;
- Remoção de componentes da topologia, respeitando a **lógica de dependência estrutural**;
- Construção de redes FTTH por meio de **interação** baseada em **cliques**;
- Sistema de ***feedback* visual e textual** com mascote pinguim;
- **Representação visual** dos principais **componentes** de uma **rede FTTH**;
- **Ambiente temático e lúdico** inspirado no Ártico;
- **Tutorial explicativo** para auxiliar novos jogadores.

# Como Executar o Projeto

## Pré-requisitos

Antes de executar o projeto, é necessário ter instalado:

- **Node.js**
- **npm** (geralmente instalado junto com o Node.js)

Você pode baixar o Node.js em:

https://nodejs.org

---
## 1. Abra seu Git Bash

## 2. Clonar o repositório

```bash
git clone https://github.com/katherinesvla/EXPEDICAOFTTH.git
```

## 3. Acessar a pasta do projeto no terminal

```bash
cd EXPEDICAOFTTH
```

## 4. Instalar as dependências

```bash
npm install
```

## 5. Executar o projeto

```bash
npm run dev
```

## 6. Abrir no navegador

Após iniciar o servidor, acesse:

```text
http://localhost:5173
```

# 🎮 Como Jogar

1. Inicie o jogo pela tela principal;
2. Acesse o tutorial para compreender os conceitos básicos;
3. Entre no mapa principal;
4. Selecione o componente orientado pelo mascote pinguim;
5. Clique no cenário para posicionar os elementos da rede;
6. Utilize as orientações do mascote durante a montagem;
7. Remova componentes quando necessário.
